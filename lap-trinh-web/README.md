# TÀI LIỆU HỌC LẬP TRÌNH WEB — HTML · CSS · JavaScript

> Bộ tài liệu dành cho **người mới bắt đầu từ con số 0**, học để chuẩn bị cho môn Lập trình Web có **đồ án cuối kỳ**. Học tuần tự theo thứ tự thư mục là sẽ đi hết chương trình môn học.

---

## 1. Nên đọc bộ tài liệu này như thế nào?

1. Đọc lý thuyết theo đúng thứ tự: `phan-0` → `phan-1` → `phan-2` → `phan-3`.
2. Khi đọc, **gõ lại code theo tay** vào VS Code chứ đừng chỉ nhìn. Gõ sai rồi sửa cũng là một cách học.
3. Mở file trong thư mục `vi-du/` và `thuc-hanh/` bằng trình duyệt để thấy kết quả thật.
4. Làm bài tập trong `phan-4-on-tap/de-cuong-on-tap.md` trước khi thi giữa kỳ.
5. Cuối kỳ đọc kỹ `phan-5-do-an/HUONG-DAN-DO-AN-CUOI-KY.md` và chạy thử `du-an-mau/` làm khuôn mẫu.

## 2. Cấu trúc thư mục

| Thư mục | Nội dung | Học khi nào |
|---|---|---|
| `phan-0-nhap-mon/` | Web hoạt động thế nào, cài đặt công cụ | Trước buổi đầu tiên |
| `phan-1-html/` | HTML: khung nội dung của website | Tuần 1–2 |
| `phan-2-css/` | CSS: trang trí, bố cục, responsive | Tuần 3–5 |
| `phan-3-javascript/` | JS: lập trình, tương tác, xử lý sự kiện | Tuần 5–7 |
| `phan-4-on-tap/` | Đề cương ôn tập + 30 bài tập có lời giải | Thi giữa kỳ / cuối kỳ |
| `phan-5-do-an/` | Hướng dẫn đồ án + dự án mẫu hoàn chỉnh | Đồ án cuối kỳ |

## 3. Các file mở lên chạy được ngay

Mở bằng trình duyệt (Chrome/Edge) hoặc qua Live Server trong VS Code:

- `phan-1-html/vi-du/index.html` — trang hồ sơ cá nhân thuần HTML
- `phan-2-css/vi-du/index.html` — cùng trang đó nhưng đã "lên đồ" bằng CSS
- `phan-3-javascript/thuc-hanh/*.html` — 3 mini app: bộ đếm số, máy tính đơn giản, trò chơi đoán số
- `phan-5-do-an/du-an-mau/index.html` — **website mẫu hoàn chỉnh** (menu, dark mode, thư viện ảnh, form kiểm tra dữ liệu) — khuôn mẫu cho đồ án

## 4. Lộ trình học gợi ý 7 tuần

| Tuần | Học gì | Kết quả phải đạt |
|---|---|---|
| 1 | Phần 0 + Phần 1 (HTML cơ bản) | Tự tạo được 1 trang giới thiệu bản thân |
| 2 | Phần 1: bảng, form, thẻ ngữ nghĩa | Tạo form đăng ký có đủ loại ô nhập |
| 3 | Phần 2 bài 1–2: chọn phần tử, màu sắc, box model | Tô màu, căn chữ, bo góc, đổ bóng |
| 4 | Phần 2 bài 3: Flexbox, Grid, position | Dựng layout: navbar + sidebar + cards |
| 5 | Phần 2 bài 4 + Phần 3 bài 1–2: responsive + JS cơ bản | Website xem tốt trên điện thoại; viết được if/for/function |
| 6 | Phần 3 bài 3–4: mảng, đối tượng, DOM | Làm được bộ đếm số và validate form |
| 7 | Phần 3 thực hành + Phần 4 ôn tập | Hoàn thành 3 mini app, giải hết 30 bài tập |

Sau đó vào `phan-5-do-an/` làm đồ án khoảng 3–4 tuần.

## 5. Ba nguyên tắc vàng cho người mới

1. **Code mỗi ngày**, dù chỉ 30 phút. Lập trình là kỹ năng vận động, không phải kiến thức đọc một lần là nhớ.
2. **Lỗi là bạn của bạn.** Đọc thông báo lỗi đỏ trong Console (F12), nó đang chỉ cho bạn chỗ sai.
3. **Không hiểu thì thử nghiệm.** Đổi một giá trị, lưu (Ctrl+S), refresh trình duyệt, xem chuyện gì xảy ra. Sự tò mò dạy nhanh hơn mọi giáo trình.
